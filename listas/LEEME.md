# Biblioteca de listas de GotchaDex

Todo archivo `.gotchadex.json` de esta carpeta aparece en la app, en **Buscar colección → Biblioteca** (o **Nueva colección → Biblioteca de listas**). Quien lo toque tendrá la colección montada al momento.

## Añadir una lista

1. En GotchaDex, monta la colección (foto del checklist, por tramos, desde una web…).
2. Menú **⋯** de la colección → **Compartir la lista**. Para la Biblioteca, mejor **sin fotos**.
3. Sube ese archivo a esta carpeta: en GitHub, **Add file → Upload files**.

El nombre del archivo es el que verá todo el mundo: ponlo claro, por ejemplo `Adrenalyn XL LaLiga 2025-26.gotchadex.json`.

Lo que hay aquí es público. Solo el dueño del repositorio puede subir o borrar listas.
