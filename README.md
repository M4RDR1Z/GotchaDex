# GotchaDex

App para Android para llevar tu colección de cartas Pokémon: sets en español e inglés, y también en japonés, coreano
y chino. Busca tu set por su nombre y se crea con todas sus cartas, rarezas e imágenes; si no está, importa su lista.

Descarga el archivo `GotchaDex-….apk` de esta página y ábrelo en el móvil. Si ya tienes la app, ella misma te avisa
cuando hay una versión nueva.
