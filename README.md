# GotchaDex

App para Android para llevar tus colecciones de cartas y cromos: Pokémon, Magic, Yu-Gi-Oh!, One Piece, Lorcana, Palworld, Dragon Ball Daima, Panini y las que quieras añadir.

Descarga el archivo `GotchaDex-….apk` de esta página y ábrelo en el móvil. Si ya tienes la app, ella misma te avisa cuando hay una versión nueva.
