# GotchaDex

App para Android para llevar tus colecciones de cartas y cromos: Pokémon, Magic, Yu-Gi-Oh!, One Piece, Lorcana, Palworld, Dragon Ball Daima, Panini y las que quieras añadir.

Las versiones están en **[Releases](https://github.com/M4RDR1Z/GotchaDex/releases/latest)**. Descarga el archivo `.apk` y ábrelo en el móvil. Si ya tienes la app, ella misma te avisa cuando hay una versión nueva.
